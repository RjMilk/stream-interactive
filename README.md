# Stream Interactive

Донаты, фоллоу, подписки и рейды из MiniChat (Twitch + YouTube + Streamix) превращаются в помехи на экране стримера и в события внутри игры.

## Запуск
1. Запусти MiniChat (он отдаёт события на `ws://localhost:4848/Chat`).
2. Запусти `start.bat`. Откроется панель, а поверх экрана встанет невидимый оверлей (мышь проходит сквозь него).
3. В панели выбери **игру** и **вариант исполнения**. Выбор запоминается.
4. В игре включи режим **«Оконный без рамки» / Borderless**. Поверх эксклюзивного полноэкранного режима оверлей не виден.

Кнопка «▶ тест» у каждой реакции запускает её без доната.

## Горячие клавиши
- `Ctrl+Shift+F12`: убрать все помехи и сразу откатить временные игровые эффекты («паника»)
- `Ctrl+Shift+F11`: пауза или включение
- `Ctrl+Shift+F10`: засчитать повтор упражнения вручную
- `Ctrl+Shift+F9`: начать отработку долга по упражнениям

Как программа устроена внутри и что делает каждая функция: [ARCHITECTURE.md](ARCHITECTURE.md).

## Игры и варианты

| Игра | Варианты | Что нужно |
|---|---|---|
| Call of Duty: MW4 | Лёгкий / Жёсткий / Хаос | ничего, только экран |
| GTA 6 | Лёгкий / Жёсткий / Хаос | ничего, только экран |
| GTA 5 (сюжет) | Только экран / Чит-коды / Мод | для мода: ScriptHookV + ScriptHookVDotNet v3 |
| Factorio | Только экран / RCON | включить RCON в игре |
| Minecraft (Java) | Только экран / RCON / Команды в чат | свой сервер с RCON или мир с читами |
| Cyberpunk 2077 | Только экран / Мод | Cyber Engine Tweaks |

В профилях CoD и GTA 6 нажатия клавиш и моды выключены совсем: в игру ничего не отправляется.

### GTA 5: чит-коды
Программа нажимает `~`, набирает код и Enter. Нужна английская раскладка. Клавиши уходят, только когда активно окно «Grand Theft Auto V».

### GTA 5: мод
1. Установи ScriptHookV и ScriptHookVDotNet v3.
2. В `profiles/gta5.json` впиши путь к игре в `connection.gameDir` (обратные косые черты удваиваются: `C:\\Games\\GTAV`).
3. В панели нажми «Перечитать настройки», затем «Установить мод в папку игры».

### Factorio: RCON
1. В главном меню зажми `Ctrl+Alt` и нажми «Настройки» → «Остальное».
2. Задай `local-rcon-socket` = `127.0.0.1:27015` и свой `local-rcon-password`.
3. Тот же пароль впиши в `profiles/factorio.json` → `connection.rcon.password`.
4. Запускай карту через «Сетевая игра» → «Создать сохранённую игру». В панели нажми «Проверить RCON».

Lua-команды отключают достижения в этом сохранении.

### Minecraft
- **RCON**: в `server.properties` поставь `enable-rcon=true`, `rcon.port=25575`, `rcon.password=...`, тот же пароль впиши в `profiles/minecraft.json`.
- **Команды в чат**: одиночный мир с включёнными читами. Программа нажимает `/`, вводит команду и Enter, когда активно окно Minecraft.

### Кнопки мода в панели
- «Что будет установлено»: показывает в логе, какой файл куда попадёт. На диске ничего не меняет.
- «Установить мод в папку игры»: копирует файлы после подтверждения.
- «Удалить мод»: удаляет только файлы Stream Interactive.

### Cyberpunk 2077: мод
Путь к игре уже вписан. В панели нажми «Установить мод в папку игры» и перезапусти игру. В консоли CET появится строка `[StreamInteractive] мост загружен`.

## Физические челленджи
Вариант «Физкульт» есть у каждой игры. Донат от 200₽ закрывает экран заставкой со счётчиком, пока камера не насчитает повторы: 40₽ = 1 отжимание, от 500₽ — приседания.

- **Камера.** В панели нажми «Найти камеры» и выбери нужную. Телефон подходит: подключи его как веб-камеру (Связь с телефоном, DroidCam, Iriun, Camo), и он появится в списке.
- **Ракурс.** Ставь камеру сбоку, чтобы в кадр попадало всё тело. На заставке видно картинку с камеры и скелет.
- **Что считается повтором.** Отжимание: локоть согнулся сильнее 100° и разогнулся больше 150°, корпус горизонтально. Приседание: колено согнулось сильнее 105° и разогнулось больше 160°, корпус вертикально.
- **Вручную.** `Ctrl+Shift+F10` засчитывает повтор, если камера ошиблась. `Ctrl+Shift+F12` снимает челлендж совсем.
- **В долг (CoD, GTA 6).** Экран не закрывается посреди матча: повторы копятся в плашке «Долг». Между матчами нажми `Ctrl+Shift+F9`, и начнётся отработка.
- **Страховка.** Через 15 минут экран откроется сам.

В правилах: `{ "type": "exercise", "exercise": "pushups" | "squats", "count": 5 }`, либо `per` и `max` вместо `count` (повторы = сумма / `per`), `"deferred": true` — в долг. Видео с камеры обрабатывается на этом компьютере и никуда не отправляется.

## OBS
- **Захват экрана**: зрители видят помехи сами. Исключение — фильтры экрана (`screenfx`): на время их работы оверлей скрыт от записи, иначе он снимал бы сам себя.
- **Захват игры**: добавь Browser Source `http://127.0.0.1:3737/overlay.html?mode=obs` размером 1920×1080. Фильтры экрана в нём показываются подписью «Экран перевёрнут (у стримера)».

## Настройка реакций
Правила лежат в `profiles/<игра>.json`, общие наборы помех — в `profiles/_shared.json`.

- Для доната выбирается правило с наибольшим `min`, не превышающим сумму в рублях. Сначала ищутся свои правила варианта, потом общие наборы из `use`.
- `random: true`: один случайный эффект из списка. `cooldown`: пауза между срабатываниями, сек.
- В командах и подписях доступны `{user}`, `{amount}`, `{rub}` и `{n}` (сумма, делённая на `per`, не больше `max`).
- `revert` + `duration`: команда отката через заданное время.
- Звук: положи файл в `public/sounds/` и добавь эффекту `"sound": "boom.mp3"`.

### Помехи экрана
| type | что делает | параметры |
|---|---|---|
| `banner` | огромная плашка с ником, суммой и сообщением | `title` |
| `crosshair` | гигантский эмодзи на месте прицела | `emoji` |
| `smoke` | дымовая завеса | `count` |
| `flashbang` | ослепление белым | |
| `tunnel` | темнота с гуляющим окошком | `radius` |
| `ink` | чернильные кляксы | `count`, `color` |
| `cracks` | разбитый экран | `hits` |
| `rain` | дождь из эмодзи | `emoji`, `count` |
| `screenfx` | фильтр живой картинки экрана | `mode`: `flip`, `mirror`, `gray`, `invert`, `blur`, `zoom`, `tiny`, `drunk`, `freeze` |

### Действия в игре
| type | что делает |
|---|---|
| `keys` | нажатия клавиш: `preset` `gta5-cheat` или `mc-command`, `text`, `repeat` |
| `rcon` | список `commands` по RCON |
| `mod` | `command` и `arg` для мода в игре |

Поле `label` показывает подпись на экране («🚓 Вася: розыск 4★»).

## Если донаты не срабатывают
MiniChat не документирует поля доната. Все сырые сообщения пишутся в `logs/minichat-raw.log`: по ним можно поправить разбор в `minichat.js`.
