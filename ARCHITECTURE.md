# Устройство программы

Как пользоваться — в [README.md](README.md). Здесь: из чего программа состоит, как идут данные и что делает каждая функция.

## Скелет

```
stream-interactive/
├─ start.bat              запуск из исходников (ставит зависимости при первом старте)
├─ package.json           зависимости, команды npm и настройки сборки установщика (раздел "build")
├─ build/                 иконка (icon.ico) и скрипт, который её рисует
├─ config.json            порт, адрес MiniChat, горячие клавиши, курсы валют, выбранная камера
├─ state.json             последняя выбранная игра и вариант (создаётся сам)
├─ main.js                точка входа: окна, локальный сервер, API, горячие клавиши
├─ paths.js               где программа, а где настройки пользователя; перенос настроек при обновлении
├─ engine.js              выбор реакции по правилам, очередь эффектов, откаты
├─ profiles.js            загрузка профилей игр и вариантов исполнения
├─ minichat.js            подключение к MiniChat и разбор его сообщений
├─ actions/               действия внутри игры
│  ├─ index.js            таблица «тип действия → функция»
│  ├─ keys.js             нажатия клавиш (чит-коды GTA 5, команды Minecraft)
│  ├─ keysender.ps1       помощник PowerShell, который реально нажимает клавиши
│  ├─ rcon.js             клиент RCON (Factorio, Minecraft)
│  └─ modbridge.js        мост к модам через файл команд + установка/удаление мода
├─ profiles/              правила: по файлу на игру + общие наборы в _shared.json
├─ mods/                  исходники модов (Cyberpunk: Lua, GTA 5: C#)
├─ public/                всё, что открывается в окнах
│  ├─ overlay.html        оверлей: помехи экрана
│  ├─ exercise.js         физические челленджи (камера, счёт повторов)
│  ├─ panel.html          панель управления
│  ├─ models/             модель распознавания позы
│  └─ sounds/             звуки эффектов
└─ logs/minichat-raw.log  сырые сообщения MiniChat
```

## Две папки: программа и настройки
| | из исходников (`npm start`) | установленная версия |
|---|---|---|
| программа (`APP_DIR`): код, `public/`, `mods/`, исходные профили | папка проекта | `%LOCALAPPDATA%\Programs\stream-interactive\resources\app` |
| настройки (`DATA_DIR`): `config.json`, `profiles/`, `state.json`, `logs/` | папка проекта | `%APPDATA%\Stream Interactive` |

При первом запуске новой версии `ensureData()` копирует в папку настроек недостающие файлы и дописывает в существующие только новые ключи: так появляются новые игры и варианты, а пароли RCON, пути к играм и правки правил остаются.

Установщик собирает electron-builder (NSIS): установка для текущего пользователя без прав администратора, ярлыки на рабочем столе и в «Пуске», удаление через «Приложения». `asar` выключен, чтобы `actions/keysender.ps1` и файлы MediaPipe лежали обычными файлами.

## Как идут данные

```
MiniChat ──ws──▶ minichat.js ──событие──▶ engine.js ──┬─ помеха экрана ──▶ WebSocket-хаб ──▶ overlay.html (окно поверх игры)
 (донат, фоллоу,   normalize()         findRule()     │                        (main.js)  ──▶ overlay.html?mode=obs (источник OBS)
  подписка, рейд)                      playRule()     │                                   ──▶ panel.html (лог, состояние)
                                                      └─ действие в игре ──▶ actions/keys | rcon | modbridge ──▶ игра
panel.html ──HTTP POST /api/*──▶ main.js (симуляция, тест правила, выбор игры, установка мода…)
```

Событие всегда имеет вид `{ type, user, amount, currency, message, service }`, где `type` — `donation`, `follow`, `subscription` или `raid`.

Эффект — объект из правила: `{ type, duration, … }`. Типы `keys`, `rcon`, `mod` выполняет сервер, все остальные уходят в оверлей.

### Сообщения WebSocket (`/ws`)
| kind | кто шлёт | смысл |
|---|---|---|
| `state` | сервер | игра, вариант, список правил, пауза, MiniChat, камера |
| `log` | сервер | строка лога для панели |
| `event` | сервер | пришло событие (донат и т. д.) |
| `effect` | сервер | показать помеху: `effect`, `ev`, `n` (сумма / `per`) |
| `clear` | сервер | убрать все помехи |
| `exercise` | сервер | команда челленджу: `rep`, `skip`, `start`, `forgive` |
| `exstate` | сервер | состояние челленджа: `{ cur: { kind, total, done, user }, debt }` |

### HTTP API (всё `POST`, тело — JSON)
| адрес | тело | действие |
|---|---|---|
| `/api/simulate` | событие | прогнать событие как настоящее |
| `/api/effect` | эффект | показать один эффект |
| `/api/rule-test` | `{ i }` | запустить правило по номеру |
| `/api/clear` | | «паника» |
| `/api/toggle` | | пауза / включение |
| `/api/reload` | | перечитать config.json и профили |
| `/api/select` | `{ profile, variant }` | выбрать игру и вариант |
| `/api/test-rcon` | | проверить связь по RCON |
| `/api/mod-plan` | | показать, что будет установлено (без изменений на диске) |
| `/api/install-mod`, `/api/uninstall-mod` | | скопировать / удалить файлы мода |
| `/api/capture` | `{ on }` | начать / закончить захват экрана для `screenfx` |
| `/api/exercise` | `{ cmd }` | команда челленджу |
| `/api/exercise-state` | `{ state }` | оверлей сообщает состояние челленджа |
| `/api/camera` | `{ label? }` | узнать или сохранить выбранную камеру |
| `/api/open-data` | | открыть папку настроек в проводнике |

## Функции

### main.js
| функция | что делает |
|---|---|
| `loadConfig()` | читает config.json |
| `broadcast(msg)` | рассылает сообщение всем подключённым окнам |
| `log(text)` | пишет строку в консоль и в лог панели |
| `state()` | собирает сообщение `state` |
| `setExerciseState(next)` | запоминает состояние челленджа, пишет изменения в лог, рассылает `exstate` |
| `exerciseCommand(cmd)` | рассылает команду челленджу (горячие клавиши и кнопки панели) |
| `setCapture(on)` | включает захват экрана для `screenfx`; на это время прячет оверлей от записи, чтобы он не снимал сам себя |
| `readBody(req)` | читает JSON из тела запроса |
| `api(pathname, body)` | обработчик всех адресов `/api/*` |
| `createOverlay()` | прозрачное окно поверх игры, мышь проходит насквозь |
| `createPanel()` | окно панели; его закрытие завершает программу |

Вторая копия программы не запускается (`requestSingleInstanceLock`): вместо неё на передний план выходит панель первой.

### paths.js
| функция | что делает |
|---|---|
| `APP_DIR`, `DATA_DIR` | папка программы и папка настроек (см. «Две папки») |
| `ensureData()` | готовит папку настроек; работает один раз на версию (метка `version.txt`) |
| `syncJson(from, to)` | копирует JSON, если его нет, иначе дописывает новые ключи; файл с ошибкой не трогает |
| `mergeMissing(target, defaults)` | рекурсивно добавляет недостающие ключи, не меняя существующие |

### engine.js — класс `Engine`
| метод | что делает |
|---|---|
| `toRub(amount, currency)` | переводит сумму в рубли по курсам из config.json |
| `findRule(ev, rub)` | ищет правило: сначала свои правила варианта, потом общие наборы; берёт наибольший `min`, не превышающий сумму |
| `handleEvent(ev)` | вход для событий: лог, пауза, поиск правила, кулдаун, запуск |
| `playRule(rule, ev)` | запускает все эффекты правила или один случайный (`random`) |
| `playEffects(effects, ev)` | ставит эффекты в очередь |
| `pump()` | запускает очередь, не больше `maxConcurrent` событий одновременно |
| `vars(effect, ev)` | значения для подстановок `{user}`, `{amount}`, `{rub}`, `{n}` |
| `run(effect, ev)` | один эффект: помеху отправляет в оверлей, действие выполняет в игре, ставит таймер отката |
| `clear()` | «паника»: чистит очередь, сразу выполняет все откаты, убирает помехи |
| `setEnabled(v)` | пауза / включение |
| `safeName(s)` | оставляет в нике только буквы, цифры, пробел, `_`, `-` — ник попадает в команды игры |

### profiles.js — класс `Profiles`
| метод | что делает |
|---|---|
| `load()` | читает все `profiles/*.json` и `_shared.json` |
| `select(profileId, variantId, save)` | выбирает игру и вариант, сохраняет выбор в state.json |
| `active()`, `variant()` | текущий профиль и вариант |
| `ruleLists()` | списки правил в порядке поиска: свои, затем наборы из `use` |
| `flatRules()` | те же правила одним списком (для панели и кнопок «тест») |
| `summary()` | краткое описание игр, вариантов и правил для панели |

### minichat.js
| функция | что делает |
|---|---|
| `connectMiniChat(url, { onRaw, onEvent, onStatus })` | держит соединение с MiniChat, переподключается с растущей паузой |
| `normalize(msg)` | превращает сообщение MiniChat в событие программы или `null` |

### actions/
| функция | файл | что делает |
|---|---|---|
| `keysAction(effect, ctx)` | keys.js | набирает текст или пресет клавишами; только если профиль разрешает ввод и активно окно игры |
| `stop()` | keys.js | останавливает помощника PowerShell при выходе |
| `rconExec({ host, port, password }, commands)` | rcon.js | подключается по RCON, выполняет команды, возвращает ответы |
| `modAction(effect, ctx)` | modbridge.js | дописывает команду в файл, который читает мод |
| `write(file, command, arg, user)` | modbridge.js | формирует строку `id\|команда\|аргумент\|ник\|;` и пишет файл |
| `modPlan(profile, root)` | modbridge.js | что и куда будет скопировано; на диске ничего не меняет |
| `installMod(profile, root)` | modbridge.js | копирует файлы мода в папку игры |
| `uninstallMod(profile)` | modbridge.js | удаляет только свои файлы |

`ctx` у действий: `{ profile, fill, n, revert }`, где `fill(строка)` подставляет `{user}` и остальные значения, а `revert: true` означает вызов отката.

### public/overlay.html
| функция | что делает |
|---|---|
| `layer(duration, fade)` | создаёт слой помехи, который сам исчезнет через `duration` секунд |
| `remove(el)` | убирает слой, останавливает его таймеры и вызывает `el._cleanup` |
| `play(effect, ev, n)` | запускает эффект по типу, проигрывает звук |
| `EFFECTS.<тип>(p, ev, n)` | по функции на эффект: `banner`, `crosshair`, `smoke`, `flashbang`, `tunnel`, `ink`, `cracks`, `rain`, `toast`, `screenfx`, `exercise` |
| `capture(on)` | просит сервер начать / закончить захват экрана |
| `connect()` | подключение к WebSocket-хабу с автопереподключением |

### public/exercise.js
Состояние челленджа ведёт только окно поверх игры. Источник OBS и панель его только показывают.

| функция | что делает |
|---|---|
| `EXERCISES` | описание упражнений: какие суставы, пороги углов, требуемая поза |
| `jointAngle(a, b, c)` | угол в суставе `b` в градусах |
| `makeCounter(kind)` | счётчик повторов; `feed(скелет)` возвращает `{ rep, hint }`. Повтор = сустав согнулся сильнее `down`, затем разогнулся больше `up` |
| `loadLandmarker()` | загружает распознавание позы MediaPipe (один раз, локальные файлы) |
| `openCamera()` | открывает камеру; если в панели выбрана другая, ищет её по названию |
| `publish()` | отправляет состояние на сервер |
| `renderDebt(debt)` | плашка «Долг: …» в углу |
| `renderCover(el, st, hint)` | заставка: заголовок, счётчик, подсказка |
| `enqueue(kind, reps, user)` | добавляет повторы к идущему челленджу того же вида или ставит новый в очередь |
| `startNext()` | берёт следующий челлендж из очереди |
| `startChallenge(c)` | заставка, камера и цикл распознавания (~15 кадров в секунду) |
| `addRep()` | засчитывает повтор; на последнем открывает экран |
| `finish(c)` | снимает челлендж и запускает следующий |
| `COMMANDS` | `rep`, `skip`, `start` (отработать долг), `forgive` (списать долг) |
| `onExerciseMessage(msg)` | обрабатывает `exercise` и `exstate` |

### public/panel.html
| функция | что делает |
|---|---|
| `post(url, body)` | запрос к API |
| `sim(type, amount)` | симуляция события из полей формы |
| `btn(text, onclick, cls)` | создаёт кнопку |
| `render(s)` | рисует игры, варианты, инструменты и таблицу правил |
| `renderExercise(st)` | строка «Идёт: … Долг: …» |
| `findCameras()` | список камер кнопками |
| `addLog(text)`, `connect()` | лог и подключение к хабу |

## Как добавить своё

- **Новая помеха экрана.** Функция в `EFFECTS` в overlay.html, затем `{ "type": "имя" }` в правилах.
- **Новое упражнение.** Строка в `EXERCISES` в exercise.js: три точки скелета, пороги `down` и `up`, поза `flat` или `upright`. Добавь название в `EX_WORDS` в main.js и panel.html.
- **Новая игра.** Файл `profiles/<игра>.json` с `name` и `variants`; появится в панели после «Перечитать настройки».
- **Новое действие в игре.** Функция в `actions/`, запись в `actions/index.js` и тип в `ACTION_TYPES` в engine.js.
